# 荣誉证书生成器（升级版）

## 已实现
- 原始证书底图与固定版式保留，指定字段可替换
- 单人填写、实时预览、打印/另存为 PDF
- Excel（.xlsx/.xls）与 CSV 批量导入
- 批量生成独立 PDF，并自动打包为 ZIP
- 浏览器本地处理证书数据，不向网站服务器上传表格内容

## 本地使用
1. 解压网站文件。
2. 双击 `index.html`，使用 Chrome 或 Edge 打开。
3. 单人生成：修改表单并点击“生成 / 打印 PDF”。
4. 批量生成：导入 Excel 或 CSV，检查上一条/下一条预览，再点击“批量生成全部 PDF（ZIP）”。
5. 打印为 PDF 时，选择 A4、横向、边距“无”，开启“背景图形”。

## Excel / CSV 格式
第一张工作表（或 CSV）按以下列顺序提供数据：
姓名、开始日期、结束日期、活动名称、荣誉称号、贡献描述、颁发日期

- 第一行可使用上述表头。
- 每一行对应一张证书。
- 日期建议在表格中直接填写为文字，例如 `2026年3月20日`。
- 可参考 `批量导入示例.csv`。
- 建议先用 2 条测试数据检查排版，再批量生成。

## 发布到 GitHub Pages
建议为基金会单独建立一个新的公开仓库（不要与 HOPE 学堂网站混用品牌和仓库），例如 `foundation-certificate-maker`。

1. 登录 GitHub，创建一个新仓库。
2. 将 `index.html` 上传到仓库根目录；可同时上传 `README.md` 和 `批量导入示例.csv`。
3. 打开仓库 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/ (root)`，点击 `Save`。
6. 等待 GitHub Pages 部署完成，页面会提供一个 `https://用户名.github.io/仓库名/` 形式的网址。

## 运行依赖与隐私说明
- 页面核心表单和证书预览在浏览器本地运行。
- Excel、PDF、ZIP 批量处理功能通过 jsDelivr CDN 加载 SheetJS、jsPDF、JSZip，因此首次使用批量导入/导出时需要联网。
- 证书数据和上传的表格在浏览器内处理，不会自动上传到 GitHub Pages。
- 若所在网络屏蔽 jsDelivr，批量功能可能无法加载；此时可更换网络或后续将依赖库下载后与网站一起部署。
- GitHub Pages 是静态托管，不提供账号权限控制。若证书内容涉及不宜公开的信息，不要将填写数据或生成的个人证书上传到仓库。
